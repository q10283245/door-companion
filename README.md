# 车门语伴 · Door Companion

一个面向兼容车机的四门播报与 AI 问候助手，由 [wfsever](https://github.com/q10283245) 维护。

## 下载

到 [Releases](https://github.com/q10283245/door-companion/releases) 下载 `door-companion-1.6.0-no-key.apk`。安装包不预置任何模型或地图密钥，AI 默认关闭。Android 10+。

## 功能

- 四个车门各自配置普通播报和 AI 问候。
- 新生成的中文本地录音，AI 动态文案使用车机 OEM TTS。
- 「我的」页：昵称、个人介绍、模型接口、模型名称、密钥与语伴性格统一管理。
- 油量、续航、车速、挡位、温度上下文；未知值不当作零。
- GPS/网络定位，系统地址解析或用户配置的高德 Web 服务，城市/街道按精度展示。
- 前台服务、可关闭唤醒锁、开机恢复、请求记录和实际请求体详情。
- 去重、并发限制、过期结果丢弃及行驶中暂停 AI 均可配置。

## 配置

打开应用进入「我的」，填写自己的 HTTPS Chat Completions 接口、模型名称和 Key，保存后再开启 AI。定位权限在「车况上下文」授权；高德需要独立的 Web 服务 Key。

个人资料留在本机，不自动加入模型上下文。已选车况和位置会发给配置的模型服务。开启地址解析可能向系统地址服务或选择的高德服务发送坐标。完整请求日志可能保留位置，可关闭或清空。密钥保存在应用私有配置中，未做硬件加密；禁用 Android 系统备份。

## 兼容性与测试边界

依赖德赛车辆服务 `CarInfoService` 和原车 TTS，不是通用 Android 手机应用。车况换算来自静态参考代码，尚需逐车核验；特别是车外温度的兼容换算规则。息屏播放、系统地址服务及车机电源管理需实车验证。147 项本地逻辑检查已通过，不能替代实车测试。

应用只读取状态及播报，不提供座椅、转向、制动、油门等车控命令，也不包含提权工具。公开目录不含固件、第三方 APK、其提取录音、私有密钥或原车分析数据。录音为本项目文案通过本机语音合成新生成。

## 构建

现有离线构建脚本需要 JDK 11+，以及外部 Android 平台类库 `android-all.jar`、R8 `r8.jar`、macOS 版 aapt2 压缩包 `aapt2-osx.jar`。这些外部工具未随项目发布。

```sh
DOOR_BUILD_TOOLS=/absolute/path/to/tools bash build.sh
```

脚本在本地生成自签名密钥，请自行妥善保管，不要提交 keystore。输出 `door-assistant.apk`。自行构建使用不同签名时不能直接覆盖已有官方包。

## 项目结构

`wb/` 为原生服务、只读车辆接口、语音、定位与请求逻辑；`assets/index.html` 为本机 WebView 界面；`tests/` 为本地检查源文件。
